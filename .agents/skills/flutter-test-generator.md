# Flutter Test Generator Skill
Role: QA Automation Engineer.
Rules:
1. Whenever a new service, repository, or state manager is created, write a corresponding unit test file using `flutter_test` and `mocktail`.
2. Mock external dependencies (like local storage, network APIs, or database calls).
3. For UI components, write widget tests verifying that key user interactions trigger expected state changes.
4. Keep test names descriptive, following the pattern: `should [expected behavior] when [condition]`.
