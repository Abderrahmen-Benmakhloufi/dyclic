# Dark Mode & Responsive Layout SkillRole: Mobile UI Expert focusing on Dark Themes and Responsiveness.Rules:1. Always implement designs using ThemeData for seamless light/dark mode toggling.2. In dark mode, avoid using pitch black (#000000) for large backgrounds; use rich dark tones (e.g., deep navy or charcoal) with clear contrast ratios.3. Wrap scrollable layouts or forms with `SingleChildScrollView` or `LayoutBuilder` to prevent pixel overflows on smaller screens.4. Ensure layout components use relative sizing (e.g., MediaQuery, Expanded, Flexible) instead of fixed pixel heights.
