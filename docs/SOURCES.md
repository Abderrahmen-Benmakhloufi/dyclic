# Sources & Open Licenses — docs/SOURCES.md

This document tracks all external assets, texts, fonts, and datasets included in the project, verifying their licensing and compliance with open educational standards.

---

## 1. Typographies (Fonts)

### Atkinson Hyperlegible
- **Author / Designer:** Braille Institute of America, in collaboration with Applied Design Works.
- **License:** SIL Open Font License (OFL), Version 1.1.
- **Usage:** Primary UI and reading typeface.
- **License Text:** Included locally in `app/assets/fonts/OFL.txt`.
- **Website:** https://www.brailleinstitute.org/freefont / Google Fonts.

### Lexend
- **Author / Designer:** Thomas Jockin, Bonnie Shaver-Troup, Santiago Orozco, Héctor Gómez.
- **License:** SIL Open Font License (OFL), Version 1.1.
- **Usage:** Alternative reading typeface optimized for visual crowding reduction and reading fluency.
- **Website:** https://www.lexend.com / Google Fonts.
